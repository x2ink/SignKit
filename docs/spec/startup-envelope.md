# 动态笔触起笔形状

## 根因

此前将 DOWN 圆点改为预览，并按第一次位移重置速度，解决了匀速情况下的圆头；但按下停顿、亚阈值抖动或缓慢起步时，第一次真实速度仍很低，前段宽度会永久留在轮廓中。增强动态响应、增大最大宽度后，这一差异更加明显。

## 形状规则

- 速度/压力模型不再增加额外启动分支，公共配置不变。
- 所有动态模式在 `VariableStroke` 每个轮廓采样点施加起笔宽度上限；固定模式不变。
- 起点上限为本笔最小宽度，随后按累计曲线路程经 smoothstep 放开到最大宽度，最终宽度取模型宽度与上限的较小值。
- 起笔长度为 `max(本笔最大宽度, 12dp)`。不使用过短的硬上限，避免粗圆在后方反向覆盖起点；64dp 画笔的40dp短笔必须仍有可感知的粗笔身。
- 路程按曲线轮廓采样点累加，不使用离起点的直线距离，因此回头和弯曲不会重新启动包络。
- 只在提交曲线段时推进路程。实时尾段和导出只读取进度，不能因预览频率不同而改变笔迹。
- 圆点采样间距同时考虑最小宽度，避免起笔变细后边缘出现波纹。
- 未移动的点按和原地压力预览仍保留独立圆点；清空和撤销照常丢弃当前笔画状态。

## 验收

按下停顿与亚阈值位移后快写，头部不能明显粗于笔身；覆盖速度与混合模式。64dp宽笔的40dp短笔，32dp位置的实际厚度至少28dp；起点细于笔身。重复预览/导出与不预览的最终位图相同。原有点按、压力、批次等价、粗细滑动条、撤销和生命周期回归继续通过。
