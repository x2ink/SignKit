# 笔宽与笔锋响应校准

## 问题

原混合映射 `pressure / (1 + velocity)` 在低压输入下使快慢笔宽都接近最小值。原示例最大宽度仅 1–20dp、默认 5dp，动态模式再缩到 25% 时，在低密度大屏上过细。

## 行为与接口

- 保留 `strokeWidth` 最大宽度语义和 `minStrokeWidthRatio`；固定模式、原有压力模式不变。
- 新增 `velocityReference: Float`，单位 dp/ms，默认 1.5，要求正有限值。此速度对应速度因子 0.5，值越大越不容易变细。按笔锁定配置。审查后采用 1.5，使较慢的书写速度也有可见变化。
- 速度因子改为 `1 / (1 + (velocity / velocityReference)^2)`，在常见速度区间保留明显差异。
- 混合因子改为 `speedFactor * (0.5 + 0.5 * pressure)`。压力仍单调影响粗细，低压时保留至少一半的速度响应范围。
- 仍映射到最小/最大宽度并滤波，首个有效移动直接初始化，避免起笔圆头回归。
- 示例滑动条改为 4–64dp、默认 24dp；显示“粗细上限”和“动态范围”，新笔生效。测试场景覆盖滑动条小、中、大位置的实际导出笔身厚度。

## 验收

同样低压力输入，0.2dp/ms 与 6dp/ms 的笔身必须有可见差异（32px上限时至少5px）；速度模式常见范围内可见变化；压力/速度仍单调；调整粗细上限明显改变相同轨迹的厚度；新增参数校验和按笔锁定；起笔无大点、历史批次一致、撤销/导出/生命周期继续通过。
