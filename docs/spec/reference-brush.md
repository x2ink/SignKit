# 基于 android-signaturepad 的动态笔触

## 目标与依据

来源：gcacace/android-signaturepad，commit `eb7cf3c8ee0c5ff693e8c746ee472cb437680c49`。动态笔触采用上游四点窗口、按相邻点距离加权的三次贝塞尔控制点、速度低通、`max(maxWidth/(1+velocity), minWidth)` 和段内 `startWidth+t³*(endWidth-startWidth)`。

删除现运行路径中的中点二次动态曲线、平方速度响应、额外宽度0.5滤波、距离起笔包络。固定模式保持已有行为。此前动态造型与校准规格为历史方案，由本文替代。

## 适配边界

真实用户截图验收后增加 [首尾宽度几何约束](endpoint-width.md)：保留这里的目标曲线/速度公式，最终渲染宽度按路程限增长、成熟尾段不回粗，移动笔画从最小宽度起。上游数值golden验证目标公式，不代表最终轮廓未经几何约束。

- 保留 SignKit 的 eventTime 与历史采样，避免用处理时刻计算速度。
- 起点重复一次满足曲线边界，不复制上游 DOWN fallthrough 的三重起点/零长度首圆；按下圆点仅是预览，不写入移动笔画。
- 按笔锁定配置，宽度/速度按笔初始化，初始段宽为最小最大宽度中点。补齐最后一段与末端像素，独立处理纯点，保留主指规则。
- `velocityReference` 保留为兼容的速度尺度（dp/ms），默认 `1/density`，使默认速度公式与上游px/ms一致。`velocityFilterWeight` 默认0.9，最小宽度比例默认3/7，与上游默认3–7dp的比例一致。
- 上游不使用pressure。SignKit额外保留压力模式：pressure线性映射宽度，混合模式取速度目标宽与压力目标宽的平均值，全部使用同一段内t³过渡，不添加起笔遮罩。压力归一化到[0,1]，raw若始终大于1，即便有变化也会被统一限制为1，原值显示不能单独证明映射有效。
- 清空、撤销、导出和原有三个生命周期保留。

## 压力核验

`InputInfo(pressure, toolType, deviceId, isContact)` 为未过滤的设备输入，新增 `setOnInputListener`。跟踪主指的当前与历史样本，包括位移过滤前的原地压力变化。UP的原始0压力也如实通知，但isContact为false，不纳入接触压力范围；笔画计算则沿用上一有效压力，避免收笔突变。

示例默认速度笔锋，另保留独立压力模式。显示当前raw pressure、工具类型、本笔压力最小/最大值；恒定输入只说明该次输入未观察到变化，不能据此断言硬件永久不支持压感。

## 验收

独立数值golden核对上游控制点、曲线点、10段长度、速度宽度序列和t³宽度插值。输入压力监听必须能展示与绘制一致的原始样本，原地变化和历史样本不丢失。动态笔画实时/完成/导出/撤销一致、样本批次等价、压力单调、固定模式和生命周期回归。显示和粗细控制继续可用。真实手指轻重输入尚需现场观察，不把合成事件成功表述成真实压感验收。
