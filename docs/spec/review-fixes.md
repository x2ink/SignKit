# 最终审查问题修复

## 收笔轮廓

速度参与的模式保留末端两倍最大笔宽范围内的完整曲线，作为可重建预览；只有离开该范围的曲线才写入已定路径。末端预览沿用目标速度公式，但不超过已定笔身的实际宽度，允许变细。尚无已定笔身时，以首个速度目标建立宽度上限，按累计路程发展短慢笔笔身；后续目标变细则降低上限，末端减速不能重新抬高上限。纯压力模式不延迟、不限制压力增长。

```mermaid
flowchart LR
    Sample[输入样本] --> Curve[三次曲线窗口]
    Curve --> Pending[末端曲线队列]
    Pending -->|离开末端范围| Committed[固定轮廓与实际宽度]
    Pending --> Snapshot[快照重建 / 宽度上限只降不升]
    Committed --> Snapshot
    Snapshot --> Output[实时 / 导出 / 完成]
```

预览和导出使用宽度模型快照，完成时提交同样的末端轮廓，重复预览不推进队列或滤波状态。此规则替代仅限制单个补齐段的旧规则，不新增公共参数。

## 中断与小高度布局

书写中禁用View按既有CANCEL语义保存当前笔画、释放父容器拦截，并恰好通知一次结束。重新启用后新笔画与前笔独立，前笔可撤销。

示例在小高度下仍有可用签名区；固定控制区可滚动。签名区尺寸无效时不能触发导出。

## 验收

连续多次慢MOVE收笔、单MOVE宽笔、短慢笔、恢复正常速度后的笔身宽度、历史批次等价、压力变化、实时/完成/重复导出一致。中断回调成对、重入、撤销与父拦截释放；小高度测量/布局后导出无异常。组件/App全量设备测试、单元测试、lint和截图核验。
