# 签名撤销规格

- 每次从按下到抬起形成一笔；单点和取消事件保留的内容也作为一笔。
- `fun undo(): Boolean` 删除最新一笔；若正在绘制，则只取消当前笔，保留之前的笔画。无可撤销内容时返回 false，成功返回 true。
- `val canUndo: Boolean` 表示有已完成笔画或当前正在绘制。
- 撤销后继续绘制产生新笔画；不提供重做。
- `clear()` 清除已完成和当前笔画，撤销不能恢复清空内容。
- 屏幕绘制和 `exportBitmap()` 使用相同笔画数据。
- 多指主指针规则保持现有行为。后续曲线与画笔配置见 [书写规格](writing.md)。
- 示例页面提供撤销按钮。

验收以导出位图验证撤销前后的笔迹是否精确恢复，并覆盖重复撤销、点按、清空、触摸取消和绘制中撤销。
