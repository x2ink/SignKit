# 动态笔画首尾宽度

## 依据

用户真实手写截图显示，多数笔画首尾有突兀圆球。保留参考实现的三次曲线、速度目标公式和t³过渡，但目标宽度必须经过几何约束后才能落成轮廓。

## 规则

- 速度型模式（VELOCITY和混合模式）在真正第一次位移时以最小宽度建立移动笔画，替代人为的中间宽度。未移动的tap仍按原逻辑画圆点。
- 每个曲线采样点先计算t³请求宽度，再限制 `actualWidth <= previousActualWidth + 0.5 * distance`，distance为两个实际曲线采样点间的像素路程。半径增长最多为路程的四分之一，避免在很短空间内形成大圆。
- 将每段最终实际宽度写回模型，作为下一段起始宽度；不再用尚未落成的目标宽度作为起点。
- 已有提交笔身的预览/收笔尾段禁止增粗，仍允许变细和绘到真实末端。只有一个MOVE、尚无已提交笔身时，尾段允许在上述路程约束下发展正常宽度。
- 纯压力模式与固定模式不加该约束；本次不调整压力采集/映射。
- 预览继续用模型快照，不改变窗口和实际宽度状态。

## 验收

停顿微移后快写、结束前1px慢移动再抬手，首尾不能形成明显宽于相邻笔身的圆球；端点坐标保留。64dp短笔仍有足够粗的笔身，单MOVE宽笔可发展宽度。重复预览、历史批次、tap、压力模式、撤销/清空及导出继续通过。最后由用户重新手写并再次截图核验，不仅依赖模拟轨迹。
