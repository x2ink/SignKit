Initial release of SignKit, a Kotlin Android signature pad.

### Features

- Smooth Bézier strokes with fixed-width, velocity, pressure, and combined pen modes.
- Configurable stroke width, minimum width ratio, and velocity response.
- Controlled width growth and stable stroke endings to reduce oversized endpoint dots.
- Stroke-by-stroke undo, clear, and undo availability checks.
- Bitmap export with transparent or custom backgrounds.
- Writing start, progress, and end callbacks.
- Raw pressure, input tool, device, and contact-state callbacks.
- Demo app with pen controls, pressure readout, and bitmap preview.

### Downloads

- `signkit-1.0.0.aar`: release build of the SDK.
- `signkit-demo-1.0.0-debug.apk`: debug-signed demo for evaluation.
- `SHA256SUMS`: SHA-256 checksums for both binaries.
- Source archives are provided automatically by GitHub for this tag.

### Requirements and integration

Android 11 (API 30) or later. This release is built with compileSdk 37.

Place the AAR in your app's `libs` directory and declare its dependencies explicitly:

```kotlin
implementation(files("libs/signkit-1.0.0.aar"))
implementation("androidx.core:core-ktx:1.19.1")
implementation("androidx.appcompat:appcompat:1.8.0")
implementation("com.google.android.material:material:1.14.0")
```

See the repository README for layout and callback examples. Pressure effects depend on the input values reported by the device. SVG export, redo, signature import, and automatic stroke-state restoration are not included in this release.
