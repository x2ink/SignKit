Bug-fix release improving stroke endpoints, writing lifecycle handling, and the demo on small windows.

### Fixed

- Velocity and combined modes now use the same initial width for contact dots and moving strokes, avoiding the large-dot-to-thin-line jump.
- A rebuildable stroke tail prevents several slow movement samples from permanently creating an oversized endpoint. Short slow strokes can still develop width; normal velocity dynamics and pressure-only behavior remain available.
- Disabling the pad while writing now completes the stroke, releases parent touch interception, and delivers one end callback. The completed stroke remains undoable, including when listeners clear or re-enable the view.
- The demo keeps a usable signature area in short windows, allows scrolling through controls, and disables export when the pad has no size. Vertical writing continues without scrolling the page.

### Documentation and validation

- Expanded the README with integration, all public pen settings, lifecycle and raw-input listeners, undo, clear, and bitmap export.
- Added endpoint, contact-width, interruption, and small-window regression coverage. The repaired SDK passed 67 Android device tests and the demo passed 9 on an Android 14 emulator; JVM unit tests, builds, and lint checks also passed.
- Demo version: `1.0.1` (`versionCode` 2).

### Downloads

- `signkit-1.0.1.aar`: SDK release build.
- `signkit-demo-1.0.1-debug.apk`: debug-signed demo for evaluation.
- `SHA256SUMS`: SHA-256 checksums for both binaries.

Android 11 (API 30) or later is required. Public API signatures are unchanged. Pressure effects depend on the input values reported by the device. See the README for AAR dependencies and usage; this release does not publish a Maven Central artifact.
